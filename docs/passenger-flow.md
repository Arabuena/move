# Fluxo do Passageiro

## 1. Onboarding
- Splash Screen
- Telas de introdução (3 slides)
- Permissões (GPS, Notificações)

## 2. Autenticação
- Login
  - Email/senha
  - Login social (Google/Apple)
  - Esqueci a senha
- Registro
  - Dados pessoais
  - Validação de celular (SMS)
  - Foto do perfil
  - Termos de uso

## 3. Home
- Barra de pesquisa endereço
- Mapa interativo
- Motoristas próximos
- Menu lateral
  - Perfil
  - Histórico
  - Pagamentos
  - Ajuda
  - Configurações

## 4. Solicitação de Corrida
- Seleção origem/destino
- Confirmação de endereços
- Escolha do tipo de carro
- Previsão de preço
- Forma de pagamento
- Botão solicitar

## 5. Aguardando Motorista
- Mapa com motoristas próximos
- Tempo estimado
- Botão cancelar
- Loading animado

## 6. Corrida Aceita
- Dados do motorista
  - Foto
  - Nome
  - Avaliação
- Dados do carro
  - Modelo
  - Cor
  - Placa
- Tempo de chegada
- Chat
- Botão ligar
- Botão cancelar

## 7. Durante a Corrida
- Mapa com rota
- Tempo estimado
- Preço atual
- Chat
- Botão emergência
- Compartilhar viagem

## 8. Finalização
- Resumo da corrida
- Valor final
- Avaliação do motorista
- Gorjeta (opcional)
- Reportar problemas

## 9. Extras
- Histórico de corridas
- Endereços favoritos
- Métodos de pagamento
- Central de ajuda
- Configurações de conta
